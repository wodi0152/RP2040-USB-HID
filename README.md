
# RP2040 USB HID

USB HID device based on Raspberry Pi RP2040.

## Features

- Keyboard Mode
- MacroPad Mode
- Music Mode
- SSD1306 OLED Display
- 4 Push Buttons

## Hardware

- RP2040 Zero
- SSD1306 OLED 128x64

## Pinout

BTN1 - GPIO2
BTN2 - GPIO3
BTN3 - GPIO4
BTN4 - GPIO5

OLED SDA - GPIO0
OLED SCL - GPIO1
